📄 1. .html과 .htm의 차이가 무엇일까요?

정답부터 말하자면, 두 확장자는 기능적으로 100% 똑같습니다! 웹 브라우저는 두 파일 모두 똑같은 웹 페이지로 인식해요.


  • 왜 두 개가 생겼나요? 아주 옛날 DOS(도스)나 윈도우 3.1 컴퓨터 시절에는 파일 확장자를 무조건 3글자(.htm)로만 써야 하는 제한이 있었어요.
  • 지금은 어떤가요? 리눅스, 맥, 최신 윈도우는 글자 수 제한이 없기 때문에 원래 풀네임인 .html을 마음껏 쓸 수 있게 되었습니다.
  • 무엇을 써야 할까요? 오늘날에는 표준이자 더 직관적인 .html 확장자 사용을 강력히 권장합니다.

🔒 2. http://와 https://의 차이는 무엇일까요?

웹사이트 주소 맨 앞에 붙는 이 글자들은 정보를 주고받는 '규칙(프로토콜)'입니다. 핵심 차이는 바로 보안과 암호화입니다.


  • HTTP (기본형): 데이터를 가공하지 않은 일반 텍스트 형태로 전송합니다. 만약 해커가 중간에 가로채면 비밀번호나 개인정보가 그대로 노출되어 위험해요! (80번 포트 사용)
  • HTTPS (보안형): 뒤에 붙은 S는 Secure(보안)를 뜻해요. 데이터를 알아볼 수 없게 꽁꽁 암호화해서 전송하기 때문에 아주 안전합니다. (443번 포트 사용)
  • 보너스 혜택: 구글 같은 검색엔진은 보안이 강화된 HTTPS 사이트를 이뻐해서 검색 결과 위쪽에 먼저 보여주고(SEO 혜택), 브라우저 주소창에 안전하다는 🔒 자물쇠 표시도 달아줍니다!
